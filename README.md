# 🏁 もふもふカート

かわいい動物キャラクターたちが走るマリオカート風 3D カートレースゲーム。
スマホ（iOS / Android）のブラウザでそのまま遊べて、ホーム画面に追加すればアプリのようにオフラインでも動作します。

- **8 体の個性的なキャラクター**（軽量 / 中量 / 重量 / 特殊）と専用ボイス・ドリフト演出・勝敗リアクション・専用カート
- **5 つのファンタジーコース**（草原・ビーチ・雪山・火山・夜の街）
- **10 種類のアイテム**（バナナ / 緑&赤のこうら / キノコ / スター / いなずま / ボム / ブーメラン / スーパーホーン / ゴールデンキノコ）
- **ローカル対戦**: 1 台で画面分割 2〜4 人（2 人は向かい合わせ表示対応）、同一 Wi-Fi 内の通信対戦
- **オンライン対戦**: プライベートマッチ（ルームコード）/ カジュアルマッチ / 観戦
- **タッチ操作 + ジャイロ + キーボード + ゲームパッド**、縦画面・横画面どちらも対応
- 3・2・1・GO! カウントダウン、順位・ラップ・ミニマップ、表彰台つきリザルト、キャラ選択とカートカスタマイズ、手続き生成のポップな BGM / SE

詳しい仕様（キャラクター提案・コース・アイテム・通信方式）は [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md) を参照してください。

## 遊び方（開発環境）

```bash
npm install
npm run dev        # http://localhost:5173  （--host 付きなので同じ Wi-Fi のスマホから http://<PCのIP>:5173 でアクセス可）
npm run server     # オンライン / LAN 対戦用サーバー (ws://localhost:8787)
```

開発モードではクライアントは自動で `ws://<アクセス中のホスト>:8787` に接続します。

## GitHub Pages で公開する

`.github/workflows/deploy.yml` が `npm ci → npm test → npm run build` を実行し、生成された `dist/` を **`gh-pages` ブランチ**へ push します。

初回だけ、GitHub の **Settings → Pages** で次のように設定してください。

| 項目 | 値 |
| --- | --- |
| Source | Deploy from a branch |
| Branch | `gh-pages` |
| フォルダ | `/ (root)` |

設定後、`main` または開発ブランチへ push（あるいは Actions タブから「Deploy to GitHub Pages」を手動実行）すると、数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` に反映されます。

> **注意**: GitHub Pages はリポジトリのファイルをそのまま配信するだけでビルドを行いません。`gh-pages` 以外（`main` や開発ブランチ）を直接公開すると、`index.html` が読み込む `src/main.js` が未ビルドのため**画面が真っ白になります**。必ず `gh-pages` ブランチを指定してください。

ビルドは相対パス（`base: './'`）で出力されるため、`/リポジトリ名/` のようなサブパスでもそのまま動きます。
公開前にローカルで同じ条件を確認できます。

```bash
npm run build
npm run check:pages   # /cart/ サブパスで配信してヘッドレスブラウザで起動確認
```

### GitHub Pages でのオンライン対戦について

GitHub Pages は静的ファイル配信のみで WebSocket サーバーを動かせません。そのため公開ページでは次のようになります。

- **そのまま遊べる**: ひとりで遊ぶ / ローカル対戦（画面分割 2〜4 人）/ タイムアタック
- **サーバーが必要**: オンライン対戦。オンライン画面の「サーバー設定」に別途立てた対戦サーバーのアドレス（例 `wss://your-server.example.com`）を入力すると使えます

対戦サーバーは `npm start` で動く Node アプリなので、Render / Railway / Fly.io などの Node ホスティングに置けます。

## 本番ビルド & 配信

```bash
npm run build      # dist/ を生成
npm start          # server/index.js が dist/ を配信しつつ WebSocket サーバーも同ポートで提供
```

`PORT` 環境変数でポートを変更できます。Render / Railway / Fly.io などの Node ホスティングにそのまま置けます（HTTPS 終端があれば `wss://` も自動）。
ジャイロ操作と PWA インストールは **HTTPS（または localhost）** が必要です。

## 操作

| 操作 | タッチ | キーボード (P1) |
| --- | --- | --- |
| ハンドル | 画面左側をドラッグ | ← → |
| アクセル | 🚀 ボタン長押し | ↑ |
| ドリフト / ブレーキ | 💨 ボタン（ハンドルを切りながら） | Shift / ↓ |
| アイテム | 🎁 ボタン（💨 と同時押しで後ろに投げる） | Space |
| ポーズ | ⏸ | Esc |

P2: `WASD` + `Q` ドリフト + `E` アイテム / P3: `IJKL` + `U` `O` / P4: テンキー。ゲームパッドも自動認識します。

## テスト

```bash
npm test           # ユニットテスト（コース生成・物理・AI・アイテム抽選・対戦サーバー・配信パス）
npm run smoke      # ブラウザ E2E（要: npx vite preview --port 4173 と npm run server を起動）
npm run check:pages  # GitHub Pages 相当のサブパス配信で起動確認（要: npm run build）
```

`npm run smoke` はヘッドレス Chromium でシングルレース／画面分割（縦・横）／オンライン 2 クライアント同期まで実際に走らせ、`test/screenshots/` にスクリーンショットを保存します。

## 構成

```
src/            クライアント（Vite + Three.js）
  core/         入力・オーディオ・設定
  data/         キャラクター / コース / アイテム / カートパーツ定義
  race/         トラック生成・物理・AI・アイテム・演出・レース制御
  ui/           メニュー・HUD・リザルト
  net/          オンライン対戦クライアント
server/         WebSocket リレーサーバー（部屋 / マッチング / 観戦 / 結果集計）+ 静的配信
docs/           設計ドキュメント
test/           ユニットテスト & E2E スモークテスト
```

新しいコースは `src/data/courses.js` に制御点を書くだけで追加できます（路面・縁石・壁・ミニマップは自動生成）。
新しいキャラクターは `src/data/characters.js` に定義を追加し、`src/race/KartModel.js` に見た目のビルダーを 1 つ足せば登場します。

## 既知の制限

- ブラウザ版のため Bluetooth の直接通信には対応していません。近くの端末同士は同じ Wi-Fi 上でサーバーを 1 台起動して遊んでください（インターネット不要）。
- キャラクターボイスのセリフは端末の音声合成（Web Speech API）を使うため、端末や OS によって声質が変わります。設定で OFF にできます。
- ランクマッチ（レーティング）は未実装で、カジュアルマッチのみです。
- GitHub Pages などの静的ホスティングでは対戦サーバーが同居できないため、オンライン対戦にはサーバーアドレスの入力が必要です（画面に案内を表示します）。
