# もふもふカート — ゲームデザイン仕様書

マリオカート風のかわいい 3D カートレースゲーム。スマホ（iOS / Android）のブラウザ・ホーム画面アプリ（PWA）として動作し、1台での画面分割対戦、同一 Wi-Fi 内の通信対戦、インターネット越しのオンライン対戦に対応します。

---

## 1. 全体像

| 項目 | 内容 |
| --- | --- |
| ジャンル | 3D アーケードカートレース |
| 対応環境 | iOS Safari / Android Chrome（PWA としてホーム画面に追加可）、PC ブラウザ |
| 画面向き | 縦・横どちらも対応（HUD と操作ボタンが自動でレイアウト変更） |
| 最大人数 | 8 人（人間 + CPU） |
| 操作 | タッチ（仮想ハンドル + ボタン）、ジャイロ、キーボード、ゲームパッド |
| 描画 | Three.js（WebGL）。アセットはすべてプリミティブと手続き生成のため軽量（gzip 約 180KB） |
| 音 | WebAudio による手続き型 BGM / SE。ボイスは合成音 + 音声合成（Web Speech API） |

### 2.1 ピョン（うさぎ）— 軽量タイプ
- **性能**: 加速が全キャラ最速。最高速はひかえめ。扱いやすく初心者向け。
- **固有特徴「ロケットスタート名人」**: スタートダッシュの成功判定が広く、被弾後の立ち直りが速い。
- **ボイス**: 「ピョン、いっくよ〜！」「ぴょんぴょんダッシュ！」「ぴゃっ！？」「おさきに〜！」

- **ボイス**: 「ホウ…わたしのばんね」「ほうっ、まいりましょう」「ほ、ほう！？」「ほうほう、けいさんどおり」
- **ドリフト演出**: 羽根がひらひら舞う。加速時は星。
- **勝利**: 首をかしげながら小さくホウホウ ／ **敗北**: 「よみがあまかったわ」とうつむく。

### 2.9 タイプ設計の考え方
- **軽量**: 加速 ◎ 最高速 △。被弾からの復帰が速いので初心者・混戦向け。
- **中量**: 平均的。ドリフトや水など得意分野で差別化。
- **重量**: 最高速 ◎ 体当たり ◎。直線の長いコース、上位維持に強い。
- **特殊**: コース依存の強み（雪・水・溶岩・夜）やアイテム系の強み。コース選択との組み合わせで戦略性が生まれる。

## 5. 操作

### タッチ（メイン）
- **画面左側**: ドラッグでハンドル（仮想ハンドルが回転）。ドリフト中は左右スワイプで曲がり具合を調整。
- **🚀 アクセル**: 押しっぱなしで加速。
- **💨 ドリフト／ブレーキ**: ハンドルを切りながら押すとホップ→ドリフト。まっすぐのときはブレーキ（停止後は後退）。
- **🎁 アイテム**: 使用。ドリフトボタンを押しながらで後方投げ。
- 設定: ボタン左右入れ替え、自動アクセル（片手用）、バイブレーション。

### ジャイロ（オプション）
- 設定画面で ON（iOS は許可ダイアログ）。縦持ち・横持ちを自動判別。感度・反転・キャリブレーション対応。

### キーボード / ゲームパッド
- P1: 矢印キー + Shift（ドリフト） + Space（アイテム）。P2: WASD + Q/E。P3: IJKL + U/O。P4: テンキー。
- ゲームパッド: 左スティック／十字キー、A アクセル、B/RB ドリフト、X/LB アイテム、Start ポーズ。

## 6. レース仕様

- **スタート**: コース紹介フライオーバー（3 秒、操作でスキップ）→ 3・2・1・GO! のカウントダウン。「1」〜「GO」の間にアクセルを押すとロケットスタート、早すぎるとホイールスピン。
- **ドリフト & ミニターボ**: ドリフト時間に応じて 青（0.9s）→ オレンジ（2.0s）→ 紫（3.2s）の 3 段階。解除時にブースト。
- **ラップ**: 進行度を連続的に追跡し逆走もカウント（逆走警告表示）。
- **順位**: 進行度で毎フレーム算出。追い抜き時に SE とボイス。
- **ゴール**: ゴール後は自動運転に切り替わりリザルトへ。全員ゴールまたは 12 秒（オンラインは 45 秒）で締め切り。
- **リザルト**: 表彰台（1〜3 位）+ 4 位以降が後列に整列。勝者はキャラ固有の勝利モーション、敗者は敗北モーション。紙吹雪とファンファーレ。
- **HUD**: 順位（大）、ラップ、タイム、アイテムスロット（ホウは 2 つ）、ミニマップ（全カートの位置）、速度、中央メッセージ、状態エフェクト（スター／ブースト／小型化）。

## 8. マルチプレイ

### 8.1 ローカル（1 台）
- 2 人: 上下分割。**向かい合わせモード**（設定・既定 ON）では上画面の映像・HUD・ボタンが 180° 回転し、端末を挟んで向かい合って遊べる。
- 3〜4 人: 4 分割（縦持ちでは縦積み）。各ビューポートに独立したタッチ操作を配置（マルチタッチ対応）。
- 「CPU で 8 人にする」で残り枠を CPU が埋める。オフラインで動作。

### 8.2 ローカル通信（同一 Wi-Fi）
- 1 台（PC またはスマホの Node 環境）で `npm run server` を起動し、他の端末は設定の「サーバーアドレス」に `192.168.x.x:8787` を入力。インターネット不要。
- ブラウザ版のため **Bluetooth 直接通信は非対応**（Web Bluetooth は iOS 未対応・データ通信用途に不向き）。Capacitor 等でネイティブ化する場合は、同じプロトコルの上に Bluetooth／Nearby トランスポートを差し替える設計になっている（`NetClient` の `send/on` インターフェース）。

### 8.3 オンライン
- **プライベートマッチ**: 「部屋を作る」→ 4 文字のルームコードをフレンドに共有。ホストがコース・周回数・CPU 補充を決めて開始。
- **カジュアルマッチ**: マッチングキューに入り、2 人以上集まって 12 秒経過（または 1 人で 24 秒）で自動開始。ランダムコース、CPU 補充。
- **観戦**: ルームコードで観戦参加。先頭付近のカートを数秒ごとに切り替えて追従。
- **同期方式**: 各クライアントが自分のカート（ホストは CPU も）を 15Hz で送信し、サーバーがリレー。受信側は補間 + 外挿。アイテムの被弾判定は「被弾側のクライアント」が行い、消滅イベントを共有。ゴールタイムはサーバーが集計して確定順位を配信。

## 9. サウンド

- BGM: コースごとにテンポ・スケール・音色の異なる 5 曲 + メニュー曲 + スター曲。16 分音符のステップシーケンサでリアルタイム合成（ドラム・ベース・パッド・リード・ディレイ）。
- SE: カウントダウン、アイテム取得ルーレット、投擲、被弾、スピン、ドリフト段階、ブースト、爆発、雷、ホーン、ラップ、ファイナルラップ、ゴール、ファンファーレ など約 40 種。
- エンジン音: 速度に応じたピッチ・フィルターのエンジン + ドリフト時のスキール音（ビューポートごと）。
- ボイス: キャラごとの基本周波数・音色の合成「鳴き声」+ 音声合成によるセリフ（ピッチ・速度をキャラ別に設定）。設定で OFF 可。

## 10. 技術構成

```
src/
  main.js            画面遷移・ゲームループ
  core/   Input.js（タッチ/キー/パッド/ジャイロ）  Audio.js（BGM/SE/ボイス）  Settings.js  Utils.js
  data/   characters.js  courses.js  items.js  kartParts.js
  race/   Track.js（スプライン→路面生成/クエリ） KartPhysics.js  AIDriver.js  ItemSystem.js
          KartModel.js（キャラ&カート 3D）  Scenery.js（テーマ装飾）  Effects.js  CameraRig.js  Race.js
  ui/     Screens.js（メニュー）  HUD.js  Results.js
  net/    NetClient.js
server/index.js      WebSocket リレーサーバー + 静的配信
```

- 物理: 進行方向と車体向きを分離したアーケードモデル（グリップで追従）。氷はグリップ低下、ドリフトは意図的な低グリップ。壁は反射・減速。
- 描画: MeshLambert + 頂点カラー、InstancedMesh で装飾。影はブロブシャドウ。低スペック端末では自動で低画質（DPR 1.25、パーティクル減）。
- 分割画面: 1 つの WebGL コンテキストでビューポート・シザー切り替え描画。HUD は DOM オーバーレイ。
